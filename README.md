# Луна — пиксельный питомец, версия 2.2

Луна гуляет, перепрыгивает на видимые блоки страницы, садится, машет рукой и засыпает. Двадцать кадров собраны в прозрачный спрайт-лист по приложенному фото.

## Установка

1. Распакуйте `luna-extension-v2.2.zip`.
2. В Chrome откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `luna-extension` с файлом `manifest.json`. Если предыдущая версия уже загружена из другой папки, отключите её, чтобы на странице осталась одна Луна.
4. Откройте обычный сайт или обновите вкладку. Настройки доступны по значку Луны в меню расширений.

## Управление

- Нажмите на Луну, чтобы она помахала. Если отпустить её на ходу, она полетит по направлению курсора. Если остановиться перед отпусканием, она упадёт прямо вниз. В обоих случаях Луна приземляется на подходящий блок или нижний край окна.
- В меню расширения есть команды «Прыгни», «Сядь» и «Спи». «Прыгни» выбирает достижимую опору рядом, а при её отсутствии запускает обычный прыжок.
- Три размера в меню соответствуют 96, 144 и 192 пикселям. На узких экранах Луна уменьшается, чтобы поместиться. Там же можно отключить самостоятельные прогулки и прыжки или скрыть Луну во всех вкладках. Системная настройка уменьшения движения по умолчанию отключает самостоятельные прогулки.
- Самостоятельная прогулка длится примерно 6–10 секунд, сидение — 6–9 секунд, сон — 12–20 секунд.
- Луна использует видимые верхние края карточек, секций и других достаточно крупных блоков. Если блок прокручивается, Луна следует за ним. Если он исчезает или полностью выходит из области прыжка, она падает на следующую опору.

Расширение запускается на страницах HTTP и HTTPS. На внутренних страницах браузера, в Chrome Web Store и в локальных файлах питомец недоступен. Спрайты и настройки хранятся локально.

## Ассеты

`assets/luna-sprites.png` — прозрачный атлас 1536 × 576 с кадрами по 192 × 192, пересобранными из исходных изображений. Линия опоры проходит по Y = 184, X-якорь на 96. В каждой строке кадры идут слева направо. При отрисовке разрешение холста подстраивается под выбранный размер и плотность экрана в пределах разрешения атласа.

| Строка | Кадры |
| --- | --- |
| 1 | Восемь фаз ходьбы |
| 2 | Покой, моргание, два кадра приветствия, подготовка, взлёт, верхняя точка прыжка, приземление |
| 3 | Две сидячие позы и два кадра сна |

В `assets/prompts.md` сохранены запросы к встроенному ImageGen. `atlas.js` содержит те же байты PNG для локальной загрузки рисунка на страницах со строгой политикой безопасности.
